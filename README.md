# Yuda Grand Prix

A retro arcade-style racing game built with React, TypeScript, and Tailwind CSS. Dodge incoming traffic, navigate oil slicks and road barriers, pick up bonuses, and race against changing day-to-night cycles.

## Live Game Link (GitHub Pages)

Your live game URL follows this format:
```
https://<your-github-username>.github.io/<your-repository-name>/
```

### How to Activate the Link on GitHub:
If GitHub Pages is not yet enabled or hasn't generated your link:
1. Go to your repository on GitHub.
2. Click **Settings** (top menu) > **Pages** (left sidebar).
3. Under **Build and deployment** > **Source**, choose either:
   - **GitHub Actions** (recommended): The included workflow builds and deploys on every push.
   - **Deploy from a branch**: Select the `gh-pages` branch and click **Save**.
4. Once selected, your live link will appear at the top of the **Pages** settings screen and in the **Actions** run summary.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```

4. Preview production bundle locally:
   ```bash
   npm run preview
   ```
